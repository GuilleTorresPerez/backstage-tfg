# Plataforma Interna de Desarrollo (IDP) — Gobierno de Aragón

La Plataforma Interna de Desarrollo (IDP) reúne el catálogo de software, la creación guiada de
proyectos y la documentación técnica de los componentes de la organización.

## Contenido

- **Catálogo de software**: sistemas, componentes, APIs y grupos responsables.
- **Plantillas**: proyectos generados mediante los *Golden Paths* disponibles.
- **Esquema Nacional de Seguridad**: controles y medidas aplicados en el prototipo.
- **Arquitectura**: vistas C4 del sistema y de sus componentes.

La documentación se publica desde este repositorio y se sirve mediante TechDocs con el almacenamiento
configurado para la plataforma.
